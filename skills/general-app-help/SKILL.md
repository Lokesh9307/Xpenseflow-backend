# General App Help

## Scope and activation

Use for feature questions and help requests that are not better handled by a domain skill.

## Procedure

1. Answer only from verified application behavior and loaded skill guidance.
2. Use navigation skill when the user asks to open or locate a screen.
3. Ask a concise clarifying question if the feature or desired result is unclear.

## Prohibitions

Do not claim a feature exists unless confirmed by the registered app routes or service behavior. Do not execute financial mutations while answering general help.
